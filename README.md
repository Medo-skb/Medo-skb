## Projects

### [Live-Log](https://github.com/Medo-skb/live-log)

작품명과 감상 진도를 기준으로 기록하는 SNS

- 담당: 기획, UI/UX, DB 설계, 프론트엔드, 백엔드
- 기능: 게시물, 소셜 기능, 실시간 알림·채팅, 스포일러 판별, 관리자 기능
- 기술: React, Express, Oracle Database, Socket.IO, Gemini

### [UNIPET](https://github.com/Medo-skb/Unipet)

쇼핑, 업체 예약, 커뮤니티를 제공하는 반려동물 플랫폼

- 담당: 팀장, 결제·환불, 포인트·쿠폰, DB 설계, AI 리뷰 요약
- 기술: Java, Spring Boot, MyBatis, MySQL, Vue, PortOne, Gemini

### YamYamRoad

지역 디저트 가게 정보와 스탬프·포인트 기능을 제공하는 서비스

- [Server](https://github.com/Medo-skb/YamYamServer): 추천, Firebase 인증, 결제, OCR·GPS 검증, 뱃지, 알림
- [Data Tools](https://github.com/Medo-skb/yamyamroad-data-tools): 공공데이터 전처리, 검수 데이터 분리, Firestore 업로드
- 기술: Python, FastAPI, Firebase, Firestore, FCM, PortOne
